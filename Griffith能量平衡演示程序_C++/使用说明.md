# Griffith 能量平衡演示程序（C++ 版）

本程序将原 Python/Tkinter 程序重写为 C++17 桌面程序。计算、图表、三维示意、鼠标交互与 CSV 导出均由 C++ 实现，采用 Windows 自带 Win32 与 GDI+。

## 直接运行

双击 **Griffith.exe**，或双击 **启动程序.bat**。

交付的 64 位 Windows 可执行文件已经编译，运行不需要 Python、Qt 或额外的 C++ 运行库。请保留源码用于后续修改；日常运行只需要 Griffith.exe。

## 页面和操作

- **裂纹模型 · 临界判定**：中心贯穿裂纹示意、载荷箭头、全长和板厚标注；下方对比 G 与 R=2γ。
- **能量平衡 · 能量曲线**：显示 Urel、S 和 ΔΠ=S−Urel，区分起裂临界半长 ac 与总能量交点 2ac。
- **参数扫描 · σc–a 曲线**：显示临界应力随裂纹半长变化，以及当前外加应力。
- **参数输入**：拖动滑块自动更新；直接填写后按 Enter，或点击“计算 / 更新”。输入框支持滑块快捷范围以外的合法数值。
- **模型交互**：左键旋转、右键平移、滚轮缩放；顶部可切换正视、俯视、等轴测视角。
- **图表交互**：移动鼠标查看数值，点击绘图区选择裂纹半长 a。
- **裂纹扫描**：依次增加裂纹半长，保持扫描期间图表尺度固定；再次点击按钮或按 Esc 停止。
- **导出数据**：导出含 UTF-8 BOM 的 CSV，可以在 Excel 中打开。保存对话框支持中文路径。
- **四个教学示例**：亚临界、临界平衡、超临界、平面应变。
- 左侧参数面板与右侧结果区均可滚动。结果区可选择文字并复制。

## 输入与公式

| 参数 | 单位 | 允许范围 |
|---|---|---|
| 弹性模量 E | GPa | E > 0 |
| 泊松比 ν | 无量纲 | 0 ≤ ν < 0.5 |
| 单位表面能 γ | J/m² | γ > 0 |
| 裂纹半长 a | mm | a > 0，裂纹全长为 2a |
| 远场拉应力 σ | MPa | σ ≥ 0 |
| 板厚 B | mm | B > 0 |

内部统一转换为 Pa、m；总能量图以 mJ 显示。平面应力与平面应变由用户选择，不根据板厚自动切换。

- E′=E（平面应力）；E′=E/(1−ν²)（平面应变）。
- 裂纹投影面积 A=2aB；两张新表面的总面积为 2A=4aB。
- 有效释放能量 Urel=πa²σ²B/E′。
- 新表面能 S=4aBγ=2γA。
- 能量释放率 G=πaσ²/E′；阻力 R=2γ。
- 临界应力 σc=√(2E′γ/(πa))。
- 临界半长 ac=2E′γ/(πσ²)；σ=0 时 ac=∞。
- 应力强度因子 KI=σ√(πa)，并有 G=KI²/E′。

**临界条件比较能量变化率 G=R。** 固定远场应力的理想曲线上，a=ac 时 Urel=S/2；Urel=S 的交点在 a=2ac。板厚影响总能量，但在所选二维状态下不影响 G、σc 和 ac。

模型为无限大板、中心贯穿裂纹、均匀远场拉伸、线弹性、理想脆性，仅计表面能。恒载时外力继续做功，应变能可以增加，Urel 表示外力功扣除应变能变化后的有效释放能量。有限试样需结合加载约束与柔度分析。扫描展示参数关系，不代表真实时间扩展；示意图开口和厚度经过视觉放大，不计算真实变形。程序不包含塑性功、有限宽修正、疲劳或裂纹扩展速率。

默认参数 E=70 GPa、ν=0.22、γ=1 J/m²、a=0.5 mm、σ=8 MPa、B=5 mm、平面应力，对应 G≈1.43616 J/m²、σc≈9.44070 MPa、ac≈0.696303 mm，为亚临界状态。

## 修改和重新编译

双击 **重新编译.bat**，将自动寻找电脑上的 g++ 编译器，重建程序并执行数值和界面检查。本机已验证使用 `C:\Dev-Cpp\TDM-GCC-64\bin\g++.exe`（GCC 9.2.0）。脚本也支持现有 `D:\CppDev\msys64\ucrt64\bin\g++.exe` 或 PATH 内的 g++。

编译需要支持 C++17 的 MinGW-w64。关闭正在运行的 Griffith.exe 后再编译，以免 Windows 锁定可执行文件。

使用 VS Code 时，打开整个 C++ 版文件夹，按 Ctrl+Shift+B 可编译此多文件项目。项目内的 `.vscode/tasks.json` 已配置构建入口。

也可以在程序目录使用终端执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

使用 CMake 和已配置的 Windows C++ 工具链时：

```text
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

提供 CMake 配置供后续开发使用；此次交付实际使用本机 g++ 构建和验证。

# Griffith 能量平衡演示程序

基于 **C++17、Win32 与 GDI+** 的交互式断裂力学教学程序，通过裂纹模型、能量曲线和参数扫描，直观展示理想脆性材料的 Griffith 能量平衡与裂纹扩展临界条件。

*An interactive Windows application for visualizing Griffith's energy balance and the onset of brittle crack growth.*

程序以无限大板中的中心贯穿裂纹为对象，支持平面应力与平面应变切换，将参数输入、模型示意、公式计算和图表分析放在同一界面中。图形界面使用 Windows 系统组件，仓库提供的 64 位可执行文件可直接运行，无需安装 Python、Qt 或额外的 C++ 运行库。

## 主要功能

- **参数联动计算**：调整弹性模量、泊松比、单位表面能、裂纹半长、远场拉应力和板厚，更新模型、曲线及计算结果。
- **二维约束状态切换**：分别计算平面应力与平面应变下的等效弹性模量和临界条件。
- **裂纹模型交互**：支持旋转、平移、缩放，以及正视、俯视和等轴测视角。
- **能量与临界条件分析**：显示有效释放能量、新表面能、总势能变化、能量释放率、临界应力、临界裂纹半长和 I 型应力强度因子。
- **曲线交互与扫描**：鼠标悬停查看数值，点击曲线选择裂纹半长，自动扫描时保持图表尺度固定。
- **教学示例**：内置亚临界、临界平衡、超临界和平面应变四个示例。
- **数据导出**：将当前参数对应的 241 点扫描数据导出为带 UTF-8 BOM 的 CSV，支持中文保存路径，可在 Excel 中打开。

## 快速开始

### 直接运行

运行环境为 **64 位 Windows**。下载仓库 ZIP 并解压后，双击 `Griffith.exe`，或双击 `启动程序.bat`。

建议先点击四个教学示例，对比不同状态下的模型与曲线，再调整参数观察变化。日常运行只需要 `Griffith.exe`；修改程序时请保留源码和构建文件。

## 输入参数

| 参数 | 符号 | 单位 | 默认值 | 允许范围 |
|---|---|---|---|---|
| 弹性模量 | $E$ | GPa | 70 | $E > 0$ |
| 泊松比 | $\nu$ | 无量纲 | 0.22 | $0 \leq \nu < 0.5$ |
| 单位表面能 | $\gamma$ | J/m² | 1 | $\gamma > 0$ |
| 裂纹半长 | $a$ | mm | 0.5 | $a > 0$，裂纹全长为 $2a$ |
| 远场拉应力 | $\sigma$ | MPa | 8 | $\sigma \geq 0$ |
| 板厚 | $B$ | mm | 5 | $B > 0$ |

默认约束状态为平面应力。程序内部统一采用 SI 单位计算；界面总能量图以 mJ 显示，CSV 中的能量以 J 导出。

默认参数下，能量释放率约为 **1.43616 J/m²**，临界应力约为 **9.44070 MPa**，临界裂纹半长约为 **0.696303 mm**。此时 $G < 2\gamma$，属于亚临界状态。

## 理论模型

### 能量与临界条件

模型采用均匀远场拉伸下的无限大板中心贯穿裂纹，裂纹全长为 $2a$，板厚为 $B$。等效弹性模量为：

$$
E' =
\begin{cases}
E, & \text{plane stress} \\
\dfrac{E}{1-\nu^2}, & \text{plane strain}
\end{cases}
$$

裂纹投影面积定义为 $A=2aB$，两张新表面的总面积为 $2A=4aB$。有效释放能量、新表面能与总势能变化分别为：

$$
U_{\mathrm{rel}}=\frac{\pi a^2\sigma^2 B}{E'},
\qquad
S=4aB\gamma=2\gamma A,
\qquad
\Delta\Pi=S-U_{\mathrm{rel}}
$$

这里的 $U_{\mathrm{rel}}$ 表示外力功扣除应变能变化后的有效机械能释放量。恒载条件下外力会继续做功，应变能本身可以增加。

能量释放率与表面能阻力为：

$$
G=\frac{\mathrm{d}U_{\mathrm{rel}}}{\mathrm{d}A}
=\frac{\pi a\sigma^2}{E'},
\qquad
R=\frac{\mathrm{d}S}{\mathrm{d}A}=2\gamma
$$

| 判据 | 程序显示 | 含义 |
|---|---|---|
| $G < R$ | 亚临界 | 能量释放率不足以克服表面能阻力 |
| $G = R$ | 临界平衡 | 达到裂纹扩展临界条件 |
| $G > R$ | 超临界 | 具有裂纹扩展驱动力 |

程序对临界状态采用相对容差：$|G-R| \leq 10^{-6}\max(G,R)$。

由 $G=R$ 可得临界应力和临界裂纹半长：

$$
\sigma_c=\sqrt{\frac{2E'\gamma}{\pi a}},
\qquad
a_c=\frac{2E'\gamma}{\pi\sigma^2}
$$

当 $\sigma=0$ 时，$G=0$，不存在有限的临界半长，程序记为 $a_c=\infty$。

I 型应力强度因子满足：

$$
K_I=\sigma\sqrt{\pi a},
\qquad
G=\frac{K_I^2}{E'}
$$

### 如何理解能量曲线

**裂纹扩展临界条件比较的是能量变化率。** 在固定远场应力的理想模型中：

- 当 $a=a_c$ 时，$G=R$，且 $U_{\mathrm{rel}}=S/2$。
- 当 $a=2a_c$ 时，$U_{\mathrm{rel}}=S$，对应两条总能量曲线的非零交点。

因此，不能将 $U_{\mathrm{rel}}=S$ 的交点作为起裂临界点。程序在能量图中分别标注 $a_c$ 和 $2a_c$，便于对照理解。

在选定的二维约束状态下，板厚影响总能量，但不改变 $G$、$\sigma_c$ 和 $a_c$。

### 适用范围

本程序用于经典 Griffith 模型的教学与参数关系分析，采用线弹性、理想脆性、无限大板和均匀远场拉伸假设，仅计入新生表面能。

模型示意中的开口与厚度经过视觉放大，不计算真实变形；参数扫描展示不同裂纹半长对应的计算结果，不表示裂纹随真实时间演化。当前模型不包含塑性耗能、有限宽修正、疲劳或裂纹扩展速率。有限试样的持续失稳行为还需结合加载约束与柔度分析。

## CSV 数据

导出文件前两行分别为模型说明和当前参数，第三行为字段名，随后为 241 行扫描数据。编程读取时应跳过前两行。

| 字段 | 含义 | 单位 |
|---|---|---|
| `a_mm` | 裂纹半长 | mm |
| `U_release_j` | 有效释放能量 $U_{\mathrm{rel}}$ | J |
| `S_surface_j` | 新表面能 $S$ | J |
| `net_release_j` | 净释放能量 $U_{\mathrm{rel}}-S$ | J |
| `G_j_m2` | 能量释放率 $G$ | J/m² |
| `R_j_m2` | 表面能阻力 $R$ | J/m² |
| `delta_total_energy_J` | 总势能变化 $\Delta\Pi=S-U_{\mathrm{rel}}$ | J |
| `sigma_c_MPa` | 当前裂纹半长对应的临界应力 | MPa |

扫描包含 $a=0$ 的曲线起点，该行的临界应力输出为 `infinity`。`net_release_j` 与 `delta_total_energy_J` 符号相反。仓库中的 [示例扫描数据.csv](./示例扫描数据.csv) 可用于查看导出格式。

## 从源码构建

### PowerShell / MinGW-w64

准备支持 C++17 的 MinGW-w64 工具链，并将 `g++.exe` 所在目录加入 `PATH`。在项目目录执行：

```powershell
# 编译图形程序和计算模块测试程序
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 编译并运行数值与界面检查
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

也可以双击 `重新编译.bat` 执行构建和检查。修改源码后，请先关闭正在运行的 `Griffith.exe`，再重新编译。

构建脚本优先使用 `PATH` 中的 `g++`，并兼容脚本中列出的两个本地安装路径。已有构建记录使用 GCC 9.2.0（MinGW-w64），C++ 标准库采用静态链接。

### CMake

需要 CMake 3.15 或更高版本，以及 Windows C++ 工具链。以下命令使用 MinGW Makefiles 生成器：

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

执行前请确保 `g++` 与 `mingw32-make` 可从终端调用。仓库提供 CMake 配置；现有构建与验证记录来自 PowerShell / g++ 流程。

### VS Code

使用 VS Code 打开项目文件夹，按 `Ctrl+Shift+B` 运行默认构建任务。需要同时验证时，在任务列表中选择“编译并验证 Griffith”。任务使用同一份 `build.ps1`，需要先配置好 MinGW-w64。
